# Spanish translation style guide

Every translator must follow these rules so the whole site reads as one voice.

## Voice
- Neutral Latin American Spanish, understandable everywhere. Avoid regionalisms (no "vosotros", no "ordenador", no "computadora" debates — the site rarely needs them).
- Address the reader as **tú** ("Consulta", "Ingresa", "Revisa"). Imperatives for buttons: "Ver", "Abrir", "Buscar", "Iniciar sesión".
- Keep the tone of the original: careful, factual, research-focused. Do not add or remove hedging ("may", "reported", "in rats") — it matters for safety.
- Sentence case for headings, as in Spanish convention (only the first word and proper nouns capitalized).

## Never change
- **Numbers, doses, units and their formatting**: copy exactly as written (`0.25 mg`, `1,250 mcg`, `10 IU`, `0.1 mL`, `3.8–6.9 hours` → `3.8–6.9 horas`). Do NOT convert decimal points to commas — a changed dose is dangerous.
- Unit symbols: mg, mcg, µg, mL, IU (keep "IU", do not write "UI"), U-100, kg.
- Peptide/compound/drug names and codes: BPC-157, TB-500, GHK-Cu, CJC-1295 DAC, Ipamorelin, Semaglutide, Tirzepatide, AOD-9604, Melanotan II, Epitalon (Epithalon), MOTS-C, etc. Keep them exactly (including capitalization).
- Brand/site name "Peptide Dosages" / "PeptideDosages.com" / "peptidedosages.com" stays as is.
- Citations: titles of scientific papers, journal names, author names, DOIs, PMIDs stay in English. Translate only connecting words like "Accessed", "checked", "Retrieved" ("consultado").
- Placeholders `<t1>`, `</t1>`, `<t2/>` …: keep every one, with the same number, wrapped around the equivalent Spanish words. You may move them within the sentence if Spanish word order requires it, but never drop, add, renumber or rename them.
- HTML entities like `&amp;` `&lt;` `&gt;` stay as entities.
